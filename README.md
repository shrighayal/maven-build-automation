# DevOps Project 3: Build Automation Using Maven

## Objective
Automate the build process of a Java application using Maven.

## Tech Stack
- Java 17
- Apache Maven
- AWS EC2 (Ubuntu 22.04)

## Project Structure# maven-build-automation

## Steps to Build
```bash
# Clone the repo
git clone https://github.com/shrighayal/maven-build-automation.git

# Navigate to project
cd maven-build-automation

# Build the project
mvn clean package

# Run the JAR
java -cp target/my-maven-app-1.0-SNAPSHOT.jar com.myapp.App
```

## Dependencies
- JUnit 4.11 (Testing)
- JUnit Jupiter 5.9.2 (Testing)
- Apache Commons Lang 3.12.0 (Utility)
